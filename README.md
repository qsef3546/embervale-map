# 엠버베일 한글 지도

[Enshrouded](https://store.steampowered.com/app/1203620/Enshrouded/)의 월드 **엠버베일(Embervale)**을 한국어로 볼 수 있는 비공식 팬 제작 인터랙티브 지도입니다.

설치나 빌드 없이 파일 네 개(`index.html`, `data.js`, `recipes.js`, `icons.js`)로 동작합니다.

## 기능

화면 오른쪽 위 **`? 사용법`** 을 누르면 지금 보고 있는 탭의 설명이 나옵니다. 번호를 붙인 화면 그림과 항목별 설명이 함께 나오고, 모달 안에서 다른 탭 설명으로 넘어갈 수도 있습니다.

그림은 `guide/*.webp` 입니다. 화면이 바뀌어 다시 만들어야 하면, 브라우저에서 화면을 캡처하고 요소 위치를 잰 뒤
`python tools/annotate_guide.py 캡처.jpg 좌표.json guide/map.webp` 로 번호를 얹습니다. 좌표 JSON 모양은 스크립트 주석에 있습니다.

### 지도

- 주요 장소·거점·수집품·기록 42종, 마커 1,018개 (한국어 이름·설명, 영문 원문 병기)
- 종류별 표시/숨김, 한글·영문 검색
- 마커별 "찾음" 표시, 우측 진행 상황 패널
- 100% 체크리스트 화면 (지도와 진행 상황 공유)
- 지도 이동(드래그), 확대·축소(휠, 두 손가락, +/− 버튼), 좌표 표시

### 제작

- 아이템 1,987종, 레시피 1,782개
- **아이템을 누르면 그 아이템으로 만들 수 있는 것을 전부 보여 줍니다** — 필요한 개수와 작업대까지
- 반대로 만드는 법(재료)도 같이 보여 주며, 양쪽 모두 트리로 계속 펼쳐 상위·하위 재료를 따라갈 수 있습니다
- 재료마다 오른쪽에 **어디서 구하는지** 표시 — 만들 수 있으면 작업대, 아니면 지역과 채집 방식
- 분류(장식·건축 / 요리·음료 / 물약·연금 / 장비·무기 / 농사·씨앗 / 기타 / 원자재) 필터, 한글·영문 검색
- 재료의 획득처(지역·채집 방식·드롭 몬스터)와 아이콘 표시. 1,987종 중 1,955종(98%)에 아이콘이 있습니다
- **옵션** — 방어구의 물리·마법 저항, 음식·물약의 지속시간과 효과, 무기의 공격 속도·퍽, 도구의 피해·내구도를 보여 줍니다 (옵션 500종 / 효과 390종)
- **설명** — 1,944종 전부 한글입니다. 고유 문장 1,096개를 옮겨 `tools/desc.ko.json` 에 두었습니다
- **심을 곳** — 묘목 53종 전부에 흙별 성장 속도와 선호도를 빠른 순으로 보여 줍니다. 자라지 않는 흙도 표시합니다

#### 할 일

- 만들고 싶은 것을 **할 일에 담아 두면 지울 때까지 남습니다** (브라우저에 저장)
- 항목마다 `+` `−` 로 개수를 조절하고, 여러 종류를 같이 담을 수 있습니다
- **담은 것 전부의 재료 총합**이 아이콘과 함께 나옵니다. 넓은 화면에서는 오른쪽 레일에 붙고, 좁아지면(1200px 미만) 화면 아래 막대로 내려갑니다
- 수량은 **제작 횟수**로 셉니다. 1회에 10개가 나오는 레시피라면 `+` 한 번이 10개씩 늘고, 재료도 한 벌씩 늘어납니다
- 주소창에 아이템이 남아 링크로 공유할 수 있습니다 (`#craft=Leather`)

찾음 표시는 브라우저의 `localStorage`에만 저장됩니다.

## 데이터 출처

- 마커 좌표·이름·설명: [The Official Enshrouded Wiki](https://enshrouded.wiki.gg/wiki/Map) 기여자들의 인터랙티브 지도 데이터 (`Map:Embervale/*`)
- 제작 레시피: 같은 위키의 Cargo `Ingredients` 테이블
- 한국어 번역, 지역 분류, 배경 지형은 이 저장소에서 새로 만들었습니다. 배경 지형은 마커 분포로 추정한 개략도이며 게임 지도 이미지를 쓰지 않았습니다.
- 지역명·장소 종류·주요 용어(어둠의 안개, 영약 우물, 망자의 전당 등)는 게임 공식 한국어판 표기에 맞췄습니다. 개별 고유명사(인물·세부 지명·문서 제목)는 음역 또는 의역이라 공식 표기와 다를 수 있습니다.
- **아이템 이름 역시 공식 한국어판을 대조하지 못했습니다.** 1,987종 전부에 한글 이름이 있지만 대부분 의역이라 게임 내 표기와 다를 수 있습니다. 특히 장식·건축물은 `수식어 + 재료 + 사물` 조합으로 옮겨서(예: `Large Boreal Wood Side Table` → `큰 한대 목재 보조 탁자`) 뜻은 통해도 게임 표기와 어긋날 수 있습니다. 고칠 곳은 `tools/names.ko.json` 에서 바로 바꿀 수 있습니다.

Enshrouded 및 관련 명칭·콘텐츠의 권리는 Keen Games GmbH에 있습니다. 이 프로젝트는 Keen Games와 관련이 없으며 비상업적 용도로만 운영합니다.

## 제작 데이터 다시 만들기

`recipes.js`와 `icons.js`는 생성 파일입니다. 위키가 갱신되었거나 한글 이름을 보탰다면 다시 만듭니다.

```bash
python tools/fetch_stats.py                                              # 아이템 설명·옵션을 위키에서 받기
python tools/fetch_growth.py                                             # 묘목의 흙별 성장 속도를 위키에서 받기
python tools/fetch_icons.py                                              # 도감에 없는 아이콘을 위키에서 받기
python tools/build_recipes.py --dogam "Enshrouded_재료도감.html"          # 캐시된 레시피로 재생성
python tools/build_recipes.py --dogam "Enshrouded_재료도감.html" --refetch # 위키에서 다시 받기
```

`fetch_icons.py` 는 받은 아이콘을 `tools/cache-icons.json` 에 모아 두고, `build_recipes.py` 가 도감 아이콘으로 덮이지 않는 자리만 채웁니다. 기본은 재료·가공품만 받고, `--scope all` 로 전체를 받을 수 있습니다(용량이 크게 늘어납니다).

한글 이름을 보태려면 `tools/names.ko.json`에 `"English Name": "한글 이름"` 형태로 추가한 뒤 다시 실행하면 됩니다. 이 파일이 도감보다 우선하며, 아이템뿐 아니라 작업대·제작자 이름도 여기서 옮깁니다.

위키 API는 요청이 잦으면 막으므로 `--refetch`는 천천히 돌아갑니다(전량 약 1분).
