# 엠버베일 한글 지도

[Enshrouded](https://store.steampowered.com/app/1203620/Enshrouded/)의 월드 **엠버베일(Embervale)**을 한국어로 볼 수 있는 비공식 팬 제작 인터랙티브 지도입니다.

`index.html` 파일 하나로 동작하며, 설치나 빌드가 필요 없습니다. 브라우저로 열면 바로 쓸 수 있습니다.

## 기능

- 지도 이동(드래그)과 확대·축소(휠, 두 손가락, +/− 버튼)
- 장소 종류별 표시/숨김, 이름 검색
- 마커를 눌러 "찾음" 표시, 탐험 진행도 표시
- 내 마커 추가(이름·종류·메모), 삭제
- 지역 목록에서 해당 지역으로 바로 이동

찾음 표시와 내 마커는 브라우저의 `localStorage`에만 저장됩니다.

## 주의

- 지형은 코드로 새로 그린 개략도이며, 지역 배치와 기본 마커 위치는 대략적입니다.
- 게임의 지도 이미지·아이콘이나 다른 지도 사이트의 데이터는 사용하지 않았습니다.
- 정확한 좌표는 [공식 위키 지도](https://enshrouded.wiki.gg/wiki/Map)를 참고하세요.
- Enshrouded 및 관련 명칭의 권리는 Keen Games GmbH에 있습니다. 이 프로젝트는 Keen Games와 관련이 없습니다.
